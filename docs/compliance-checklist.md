# 版权合规自查清单

每新增一条馆藏，**逐项打勾**后再提交。任何一项不通过，该条目不得收录。

## A. 词曲权利

- [ ] A1. 已确认作品类型（古典 / 民歌 / 戏曲 / 历史歌曲 / 其他）。
- [ ] A2. 已查明全部词曲作者及**生卒年份**（含改编者、译配者——任一 contributors 未过期即整曲排除）。
- [ ] A3. 最后一位相关作者去世已满 50 年（中国大陆标准）。
- [ ] A4. 民歌、戏曲等无固定作者的传统作品，已确认无现代改编版本混入（现代编配受保护）。

## B. 录音权利

- [ ] B1. 已确认录音的**录制年份**（不是发行年份——两者都可能相关，取更保守者）。
- [ ] B2. 美国规则：录音年份 ≤1925（已 PD），或权利人已明确释放（MMA 规则详见收录规范 1.2）。
- [ ] B3. 中国规则：录音首次固定已完成 50 年以上，或权利人已明确释放。
- [ ] B4. 若为当代录音：录制方已书面/页面声明 Public domain 或 CC0（如 Musopen、演奏者自行上传声明）。
- [ ] B5. 美国联邦政府作品（军乐团等）已核实为官方职务作品（17 U.S.C. §105）。

## C. 许可标注

- [ ] C1. 来源档案库文件页明确标注 **Public domain** 或 **CC0**（截图或存档备查）。
- [ ] C2. 不属于 CC-BY / CC-BY-SA / CC-NC 等其他许可（NC 绝对排除；BY/SA 本馆按红线排除）。
- [ ] C3. 许可信息已写入条目 `source.license` 与 `source.licenseNote`（含跨辖区要点）。

## D. 来源与溯源

- [ ] D1. `source.page` 指向档案库**文件页**（如 `https://commons.wikimedia.org/wiki/File:...`），非裸文件、非转载页。
- [ ] D2. 已实际点开来源页核对：作者、许可协议、数字化来源三要素齐全。
- [ ] D3. 音频直链可用（HTTP 200），且属于来源库本身（而非第三方镜像）。

## E. 标注完整性

- [ ] E1. 作品名称（含外文名）、作者生卒年、表演者、录制年份齐全。
- [ ] E2. 时长为实际值或 0（播放时自动读取）；文件大小与音质说明准确。
- [ ] E3. 背景介绍 100—200 字，事实可查证，不确定处写明「待考」。
- [ ] E4. 分类归属正确（六大馆区之一），标签与场景匹配合理。

## F. 跨辖区冲突（如适用）

- [ ] F1. 若录音在任一重要辖区（中/美/欧）仍受保护 → 已按「档案条目」处理：仅收手稿/乐谱/标签图档，不收音频，并在 `audioNote` 说明原因。
- [ ] F2. 档案条目已提供权威调阅指引（来源库 + 检索路径）。

## G. 提交

- [ ] G1. 通过「数据管理」页导入校验（标题/来源/音频或乐谱必填项全部通过）。
- [ ] G2. 在本地或部署环境试播放/试预览一次，确认可用。
- [ ] G3. `data/music.json` 与 `data/music.js` 已同步。
- [ ] G4. 变更说明已记录（加歌日期、来源核查日期、核查人）。
