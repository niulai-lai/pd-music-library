# 公有领域音乐收录规范

本规范是「公有领域音乐图书馆」的**第一优先级文档**。任何条目在上架前必须满足本规范全部要求；与本规范冲突时，以更严格的标准执行。

## 1. 收录范围

### 1.1 作品（词曲）层面 —— 满足任一即可

| 类型 | 标准 |
| --- | --- |
| 古典音乐 | 作曲家（及改编者、校订者等对作品版式有贡献者）去世满 50 年，且作品首次出版已满 50 年 |
| 民间音乐 / 传统戏曲 | 作者不明的传统曲调、民歌、戏曲程式（自古流传，无权利主体） |
| 民国老歌 / 历史歌曲 | 词作者与曲作者均去世满 50 年 |
| 红色歌曲 | 同上；特别注意**词与曲分别核查**（常见错误：曲已过期而词仍受保护，或反之） |

### 1.2 录音（制品）层面 —— 必须同时满足

录音制品的权利独立于词曲权利，须逐件核查：

| 辖区 | 标准 |
| --- | --- |
| 中国 | 首次制作完成后满 50 年（《著作权法》对录音制品的保护期） |
| 美国 | 依《音乐现代化法案》（MMA, 2018）：**1925 年及以前**录制的唱片已进入公有领域；1926—1946 年录制需满 100 年；1947—1956 年需满 110 年；1957 年及以后按一般 95 年规则 |
| 欧盟 | 通常为首次发表后 70 年（各国有差异） |

### 1.3 许可声明层面 —— 满足任一即可

- 权利人明确声明 **CC0**（公有领域贡献）；
- 档案库文件页明确标注 **Public domain** 且本规范 1.1/1.2 核查通过；
- 美国联邦政府作品（如美军乐团官方录音）依 17 U.S.C. §105 不受版权保护。

### 1.4 现代录音的特别通道

当代乐团或个人对公有领域作品的**新录音**，其录音本身受保护；仅当录制方明确释出为 Public domain 或 CC0 时方可收录（示例：Musopen 计划录音、演奏者自行上传 Commons 并声明 PD 的录音）。

## 2. 排除清单（红线，一票否决）

- 仍在版权保护期内的流行音乐、当代音乐、商业唱片；
- 一切盗版音频链接、破解资源、网盘转载；
- 未经授权的翻唱、Remix、重制版、当代商业录音（即使所涉词曲已过期）；
- 词或曲任一作者未过「去世后 50 年」的歌曲（例如歌词仍受保护的作品，整曲排除）；
- 仅 CC-BY / CC-BY-SA 等需署名或同源共享许可的资源（本馆仅收 PD 与 CC0，避免许可混用风险）。

## 3. 标注要求

每条馆藏必须完整标注，缺一不可：

1. 作品名称（含外文名如可考）；
2. 作者及**生卒年份**（词曲分开标注）；
3. 表演者（乐团/演奏家/录音者，不详写「佚名」并说明）；
4. 录制年份（不详写「年份未详」，不得臆测精确年份）；
5. 版权状态及依据（许可名称 + 跨辖区要点）；
6. 来源出处链接（指向档案库**文件页**，而非裸文件地址）；
7. 背景介绍 100—200 字（信息须准确，不确定处写「待考」）。

## 4. 跨辖区冲突处理

当词曲已过期、但特定辖区录音权未过期（典型：1935 年《义勇军进行曲》百代首版）：

- **不收录该录音外链**；
- 建立「档案条目」：收录手稿、乐谱、唱片标签等图档，说明无音频原因与调阅途径；
- 待全部相关辖区届满后再行收录音频。

## 5. 数据来源要求

- 音频与乐谱一律**外链**公开档案库（Wikimedia Commons、Internet Archive 等），本站不存储文件；
- 优先选择支持 CORS 的存档直链，以获得完整播放体验；
- 引用 Commons 文件时，来源页必须给出（页面本身载明作者、许可、数字化信息）；
- 收录前通过档案库 API 或文件页**逐件**核对许可标注，不以检索结果标题为准。

## 6. 移除机制

- 页脚固定免责声明声明了移除通道；
- 收到侵权通知后：立即下线对应条目（从 `data/music.json` 删除该对象或页面标记下架），并在变更记录中留存处理说明；
- 涉嫌争议的条目在核查期间先行隐藏。

## 7. 版本记录

本规范随法律与平台变化修订。重大修订需同步检查既有馆藏是否仍符合新标准。
